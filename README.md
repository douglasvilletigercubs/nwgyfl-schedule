# NWGYFL 2026 Schedule

The proposed 2026 season schedule for the NorthWest Georgia Youth Football
League: 208 league games plus the 11U/12U and 5U crossover seasons, readable
by org, by age group and by week.

Live at https://douglasvilletigercubs.github.io/nwgyfl-schedule/

One self-contained HTML file, generated by the league's schedule tool. Served
from an ordinary URL rather than an embedded viewer, so the Print button works:
it prints whichever view is on screen, laid out for black and white, with home
games shaded, crossover games marked by a left rule and neutral sites outlined.
